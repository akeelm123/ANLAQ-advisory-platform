# ANLAQ TCI™ evidence workbench — v0.1.0-rc.1

Synthetic evidence collection candidate; not a released platform. Open index.html locally. If file hashing is unavailable on the file protocol, run python3 -m http.server 8765 --bind 127.0.0.1 from this directory and open http://127.0.0.1:8765.

The approved register version is 1.0-reconstructed-rc.1. The immutable original artefact retains its candidate label; approval.json records the subsequent owner approval against the precise register commit and SHA-256. The source projection preserves 28 criteria, 32 catalogue items and 89 exact criterion relationships. Related evidence can only use an approved criterion mapping; ad hoc evidence is separately identified. Receipt is not sufficiency, and criterion coverage is not validation. Evidence class and evidence strength are independent.

Record scope; request evidence; select criterion; capture synthetic document digest and provenance; draft a traceable finding; obtain independent review; export/restore an RC.1 snapshot in a blank session. Older alpha and beta snapshots are intentionally rejected to prevent unreviewed migration. Structural replay is not authentication. The original document is not retained, and no score or executive decision can be issued.

Run node --test core.test.cjs (23 controls). Run browser-smoke.cjs with Playwright and Chrome installed. See TEST-RESULTS.txt and ACCEPTANCE-v0.1.md. Real client data, final validation rules, pilot calibration, secure document handling and formal release approval remain out of scope of this candidate. Main and Pages deployment are not changed.
